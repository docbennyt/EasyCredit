# EasyCredit Documentation

Welcome to the EasyCredit documentation hub. This documentation serves users, administrators, and developers working with the EasyCredit platform.

## What is EasyCredit?

EasyCredit is a mobile-first, offline-capable Progressive Web App (PWA) designed for small businesses, informal traders, family ventures, agents, and shop owners. It helps you track:

- **Customer Credit** - Money customers owe you
- **Customer Change** - Change/balance you're holding for customers
- **Multiple Ventures** - Manage separate businesses independently
- **Cashflow Insights** - Understand your money patterns
- **Customer Reliability** - Know who pays on time
- **Follow-up Priorities** - Focus on what matters today

## Documentation Principles

All EasyCredit documentation follows these principles:

- **Clear** - Easy to understand, even for non-technical users
- **Practical** - Focus on real-world usage
- **Honest** - No overpromising or vague marketing
- **Business-Aware** - Written for people running businesses
- **Simple** - Avoid unnecessary jargon
- **Trustworthy** - Accurate and transparent
